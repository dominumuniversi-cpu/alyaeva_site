Площадки

Подключите те, куда публикуете. Пустое поле не стирает прежнее значение, токены хранятся шифром.

Где взять токены — по шагам
  1. Telegram. Напишите @BotFather → /newbot → скопируйте токен. Бота добавьте в свой канал администратором.
  2. ВКонтакте. Создайте приложение на vk.com/apps → в нём получите токен с правом «управление сообществом» → вставьте токен и id группы.
  3. Одноклассники. Создайте приложение на ok.ru/dev/methods → возьмите ключ приложения и access_token.
  4. Instagram. Нужен бизнес-аккаунт и токен в Instagram Graph API — обычно его выдаёт тот, кто ведёт рекламу.
  5. Вставьте значения в поля ниже, нажмите «Сохранить площадки» и дождитесь ответа «Сохранено».
Если не заработало — что это может быть?
  • Токен скопирован не целиком — вставьте заново без лишних пробелов?
  • Бот добавлен в канал, а права «публиковать сообщения» у него нет?
  • Группа ВКонтакте закрытая — возможно, поэтому публикация не проходит?
  • Для Одноклассников нужны и ключ приложения, и access_token — заполнены оба?
