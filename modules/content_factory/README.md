# Контент-завод (`modules/content_factory`)

Один материал — готовые тексты для Telegram, ВКонтакте, Одноклассников, Instagram и любого
внешнего API (вебхук). Пишете один раз: завод подгоняет длину, разметку и подпись под каждую
площадку, показывает результат, публикует и хранит, что ушло, а что нет.

Отдельный модуль: **не импортирует ни одного файла сайта**. Сайт отдаёт ему три вещи —
доступ к базе, шифрование и две функции-хука. Поэтому его можно перенести на другой сайт,
поменяв только маленький файл-склейку (у alyaeva.pro это `app/content_factory_glue.py`).

## Что умеет

| Возможность | Как сделано |
|---|---|
| Адаптация под площадку | `adapt.py`: лимит длины, разметка (HTML/простой текст), подпись @аккаунта; обрезка по границе слова и закрытие тегов |
| Правка текста вручную | варианты хранятся в `cf_variants`, правка помечается `edited_by_human` и не затирается |
| Публикация | `channels.py`: Telegram (sendMessage/sendPhoto), ВК (wall.post), ОК (mediatopic.post), Instagram (Graph media + media_publish), вебхук |
| Очередь и расписание | `queue.py` + `worker.py`: атомарный захват поста (`UPDATE … WHERE status='queued'`), фон раз в 30 с, повторы |
| Защита от двойной отправки | `cf_fingerprints`: SHA-256 от площадки, адреса и текста |
| Автогенерация | `llm.py` + `generator.py`: любой OpenAI-совместимый сервис (DeepSeek, OpenAI, OpenRouter) и Perplexity как «разведка»; нет ключа — кнопка серая с просьбой подключить |
| Настройки площадок | `settings.py` → `app_settings` с префиксом `cf.`; токены шифруются |

## Как подключить к сайту

1. Скопировать каталог `modules/content_factory` в корень проекта.
2. В коде приложения (при импорте) вызвать `wire()` — отдать адаптеры базы, шифрования и хуки:

```python
import content_factory_glue as cf
cf.wire()                       # база + шифрование + хуки
from modules.content_factory.routes import router as cf_router
app.include_router(cf_router)   # страница /admin/posts и её приёмы
```

3. После открытия пула БД (в lifespan!) вызвать `cf.start()` — создаст таблицы и поднимет
   фонового исполнителя. **Раньше пула нельзя**: пул закрыт, таблицы не создаются, завод
   молча пустой.

4. Добавить маршрут в nginx: `location /admin/ { … }` (у alyaeva.pro такие уже есть).

## Адаптеры (что должен дать сайт)

```python
content_factory.connect(db)   # db.run(sql, args) / db.one / db.value / db.tx()
content_factory.secure(encrypt, decrypt)   # обе — строки
hooks.admin = admin          # (request) -> (user, None) либо (None, Response-отказ)
hooks.render = render        # (request, template, **ctx) -> HTML-ответ
```

Пример всех четырёх в одном месте — `app/content_factory_glue.py` (около 80 строк).

## Файлы

| Файл | Ответственность |
|---|---|
| `platforms.py` | справочник площадок: название, лимит, разметка, подпись, что нужно для подключения |
| `adapt.py` | калькулятор адаптации: markdown → HTML/текст, обрезка, балансировка тегов |
| `channels.py` | отправка в каждую сеть; тела запросов и разбор ответов |
| `queue.py` | очередь: захват поста, отпечатки, статусы по площадкам, расписание |
| `worker.py` | фоновый проход раз в 30 с (`CF_WORKER=0` выключает) |
| `access.py` | единственный мост к таблице постов сайта (`posts`) |
| `schema.py` | таблицы модуля, идемпотентно (`IF NOT EXISTS`) |
| `settings.py` | настройки в `app_settings` с префиксом `cf.` |
| `llm.py`, `generator.py` | подключение нейросетей, стиль, генерация, история |
| `routes.py` | страница и приёмы (`/api/admin/cf/…`) |
| `hooks.py` | места, куда сайт подставляет свои функции |
| `tests/test_module.py` | 11 проверок калькулятора — без базы и сети (`python modules/content_factory/tests/test_module.py`) |
| `tests/live_check.py` | сквозная проверка на живой базе (нужны переменные окружения сайта) |

## Таблицы

| Таблица | Что хранит |
|---|---|
| `cf_variants` | тексты поста по площадкам + отметка ручной правки |
| `cf_targets` | подключения площадок (адрес, зашифрованный токен, подпись) |
| `cf_fingerprints` | отпечатки уже опубликованного — защита от повторной отправки |
| `cf_generations` | журнал автогенераций: кто, чем, что на входе и что вышло |
| `cf_llm` | подключённые нейросети (ключ зашифрован) |

Посты лежат в таблице сайта `posts` (так сайт сам решает, где его контент).

## Чего модуль НЕ делает

- не хранит пароли и не заводит пользователей — права спрашивает у сайта через `hooks.admin`;
- не рисует шапку и меню — страница подключается к оболочке сайта (`base.html`);
- не заменяет страницу «Интеграция» (`/admin/hooks`): там приём сообщений, здесь — публикация;
- не гарантирует, что сеть примет пост: при отказе площадка помечается, текст ответа сохраняется.

