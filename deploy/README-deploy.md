# deploy/ — снимки конфигурации прода

**Не инструкция.** До 26.11.2026 файл README отсюда описывал установку «с нуля»
(webroot-сертификаты, self-signed, порт 80 для ACME) — по нему нельзя поднять текущий
прод: порт 80 снаружи перехватывает провайдер, серт перевыпускается по TLS-ALPN-01,
а копирование этого конфига на прод повторяет падение 502 (разбор — docs/deploy.md).

## Что здесь что

| Файл | Что это |
|---|---|
| `conf.d/alyaeva.pro.conf` | слепок живого vhost; обновлять при правках живого |
| `docker-compose.yml` | историческая схема развёртывания статики; прод живёт иначе (контейнеры `alyaeva-site`, `proxy`, сеть `npc-proxy-net`) |
| `site-nginx.conf` | конфиг внутреннего контейнера статики — актуален |

## Как на самом деле делается

- Деплой приложения: `node scripts/deploy-guarded.js` — кандидат проверяется до переключения; окно простоя — единицы секунд (разрешено владельцем, docs/deploy.md).
- Статика главной: `node scripts/deploy-site.js` → `E:\DockerData\alyaeva\html`.
- Сертификаты: `node scripts/renew-cert-guarded.js` (TLS-ALPN-01; домены `alyaeva.pro` и `www`, с 23.11.2026).
- Правила и разборы: `docs/deploy.md`, `docs/rules.md`.
