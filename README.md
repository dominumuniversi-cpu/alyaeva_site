# alyaeva.pro — сайт Алёны Аляевой

Именные книжки-сказки для детей, фотокниги. Екатеринбург, доставка по РФ.

**Живой сайт:** https://alyaeva.pro

## Что это

| Часть | Что делает |
|---|---|
| `app/` | Backend: FastAPI + PostgreSQL. Личный кабинет, админка, заказы, библиотека фото, единый инбокс |
| `build/` | Собранная статика сайта |
| `manifests/` | Разбор шаблона на блоки (токены, кнопки, формы) |
| `seo/` | Семантическое ядро, план, регламент ревизий |
| `scripts/` | Проверка живости, продление сертификата, SEO-ревизия |

## Задачник

Все задачи — в [Issues](../../issues). Метки:
- **Бэклог** — в очереди
- **В работе** — делается сейчас
- **Сделано** — готово и проверено
- **Слой N** — к какому этапу относится

## Разработка

```bash
# приложение
cd app
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

База: PostgreSQL, схема в `app/sql/001_init.sql` (только добавляющие миграции).

## Правила

- **Сайт не ронять.** Работы только бесшовно, проверка: `node scripts/check-live.js`
- Секреты — не в коде. Токены интеграций хранятся в БД зашифрованными
- Соседние стенды (другие контейнеры, nginx-роуты) не трогать
