## Чего ещё не хватает (по приоритету)

### 1. Индексация — без этого SEO не работает
- **SSL**: сайт до сих пор с самоподписанным сертификатом. Поисковики такой домен не индексируют — блокер №1.
- Добавить в **Яндекс.Вебмастер** (подтверждение файлом `yandex_XXXX.html` или meta-тегом).
- Добавить в **Google Search Console**.
- Отправить sitemap вручную в обе панели.

### 2. Аналитика
- **Яндекс.Метрика** — без неё не видно ни трафика, ни поведенческих.
- GA4 — опционально (в РФ сейчас чаще только Метрика).
- Цели: клик по Telegram / WhatsApp / телефону.

### 3. Контент — главный драйвер роста
- Сейчас одна страница + один лендинг. Для выдачи по «книга для ребенка с именем» мало — нужны **отзывы с фото работ** (главный недостающий контент: соцдоказательство).
- Рекомендую 3–4 страницы: `/skazki/` (каталог примеров), `/uslugi/` (все услуги), `/o-mne/` (E-E-A-T: автор, опыт).
- 1–2 статьи в месяц: «Как выбрать подарок на 1 год», «Что подарить крестнику» — захват подарочного long-tail.

### 4. Техническое
- После выдачи SSL прогнать PageSpeed / Core Web Vitals (сейчас мобильный Lighthouse блокируется самоподписанным сертом).
- Видео 4.1 МБ отдаётся по клику (preload=metadata), для мобильных стоит сжать до ~2 МБ.
- `?utm`-мусор закрыт Clean-param.

### 5. Внешнее (позже)
- **Яндекс.Бизнес** — карточка организации с фото и отзывами в Екатеринбурге; сильно для гео-запросов.
- Ссылки с локальных площадок: Е1.ру, 2ГИС, ВК-группы Екатеринбурга, Авито (nofollow, но даёт трафик).
- ВК-сообщество vk.ru/neuroart_ekb — вставить на него и на сайт перекрёстные ссылки.

## Как часто актуализировать ключи

| Задача | Частота | Зачем |
|---|---|---|
| Проверка подсказок Яндекса | **раз в 3 месяца** | Новые формулировки; сезон (сентябрь–март) меняет запросы |
| Частоты Wordstat | **раз в квартал** (нужен аккаунт Яндекса) | Отделить реальные объёмы от хвостов |
| Title/description под сезон | **перед октябрём и декабрём** | Пики «подарок на Новый год», «на день рождения» |
| Новые статьи | **1–2 в месяц** | Постепенный рост по long-tail |
| Пересмотр структуры | **раз в 6 месяцев** | Какие страницы растут, какие объединять |
| Позиции и трафик | **раз в месяц** | Контроль и раннее обнаружение проседания |

**Правило:** словаря «навсегда» нет. Ключи живут 3–6 месяцев, но переписывать целиком нельзя — поисковик заново оценивает релевантность. Меняйте точечно: title/description и 1–2 абзаца текста.

## Что нужно от владельца

1. **SSL** (проброс 80/443 или API-токен reg.ru) — блокер.
2. Номер **Яндекс.Метрики** (или доступ к аккаунту, чтобы создать счётчик).
3. Доступ к **Яндекс.Вебмастеру** и **Google Search Console**.
4. 3–5 **отзывов клиентов** с фото книг — лучший контент для дальнейшего роста.
5. Фото работ (примеры книг) для каталога `/skazki/`.
