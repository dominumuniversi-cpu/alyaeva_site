# Манифест 11 — Инпуты и формы

## Текущее состояние
Форм на сайте НЕТ — весь контакт через мессенджеры (Telegram/WhatsApp/VK/телефон). Это осознанный минимум: нет бэкенда — нет вектора атак (спам, инъекции, CSRF).

## Манифест на будущее (если появится форма заявки)
- Поле: input/textarea, Nunito 16px, padding 14px 18px, border 1.5px #DCD3F7, radius 16px, focus: border #4B4690 + тень.
- Кнопка отправки — .btn--primary (манифест 10).
- Отправка: только fetch на backend/на проксированный сервис форм; никакого mailto.

- Никогда не хранить персональные данные детей (фото/имена) на сервере без явного согласия — 152-ФЗ.
