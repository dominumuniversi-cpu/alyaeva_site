# Манифест 00 — Дизайн-токены сайта alyaeva.pro

Источник: «Сайт_визитка_Алены_Аляевой_–_Яркая_версия.html» (SingleFile-выгрузка, все ресурсы встроены).

## Роль бренда
Нейрофотограф / AI-креатор, Екатеринбург. Тёплый, сказочный, «подарочный» тон.

## Цвета
| Токен | Значение | Использование |
|---|---|---|
| --color-bg-default | #FFFFFF | базовый фон |
| --color-text-strong | #2A2650 | заголовки (тёмно-фиолетовый) |
| --color-text-body | #4A4678 | основной текст |
| --color-accent-primary | #4B4690 | кнопки-акценты, линки |
| --color-accent-soft | #7570B8 | ховеры |
| --color-bg-cream | #FFF1C7 | секция статистики |
| --color-bg-peach | #FFEBE0 | секция «Сказки» |
| --color-bg-lilac | #E6DFFA / #ECE8FA / #F1ECFF | видео, заказ |
| --color-bg-mint | #EAF7F4 / #C8EEE9 / #C6E8E2 | «Ещё я создаю» |
| --color-chip-yellow | #FFE7A0 | чипы/плашки |
| --color-chip-pink | #FFD3DA | чипы/плашки |

## Типографика
- Заголовки: `'Philosopher', Georgia, serif`
- Текст: `'Nunito', system-ui, sans-serif`
- H1: clamp(38px, 6.5vw, 64px); H2: clamp(32px, 5vw, 46px); подзаголовки 26–32px; body 16–17px; caption 15px.

## Форма
- Контейнер: max-width 1120px.
- Радиусы: pill-кнопки 999px; карточки 28px; аватары/иконки 50%; крупные блоки 32px.
- Секции: вертикальный ритм 56px/80px padding, фон — чередование пастельных плашек (см. цвета).
