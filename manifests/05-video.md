# Манифест 05 — Видео-секция (#video)

## Состав
- H2: «Посмотрите, как это бывает».
- Абзац-описание.
- Чипы: «Ребёнок — главный герой», «Книги-сказки с вашими фото».
- CTA-кнопка «Заказать сказку» → #zakaz.
- <video> с poster и текстом fallback «Ваш браузер не поддерживает видео».

## Правила
- Видео — файлом mp4/webm, preload="none", poster обязателен (иначе секция тяжёлая).
- Альтернатива для мобильных: YouTube/VK-iframe c loading="lazy" + facecache-обложка.
