{# Вопросы владельца 26.11.2026: «Код подтверждения VK — какой и где взять?», «Секрет событий VK — что это?», «Сообщество для публикаций — токена не хватает?» #}
Сообществом-получателем. Сейчас: {{ vk_token_mask }}. Пустое поле — не менять.
ID — без минуса (минус VK добавляет сам, это «от имени сообщества»). Токен выше должен быть выдан этого же сообщества — токен не может публиковать в чужое. Порядок: сообщество → «Управление» → «Работа с API» → «Создать ключ» с правами «Сообщения» и «Записи на стене» → вставить сюда. Сейчас: {{ settings.get('vk.group','') or 'не задано' }}.
VK сам придумывает эту строку и показывает её ровно один раз, при подключении Callback API. Где взять: сообщество → «Управление» → «Работа с API» → «Callback API» → вкладка «Настройки сервера» → вписать адрес {{ site_url }}/hooks/vk → VK покажет строку подтверждения — скопировать сюда и сохранить. Сайт вернёт её VK, и события включатся. Сейчас: {{ 'задан' if vk_confirm_set else 'не задан' }}. Для одних только постов этот код не нужен.
Придумываете вы сами (любая строка) и вписываете в двух местах: здесь и в VK на той же странице Callback API (поле «Секретный ключ»). VK присылает его с каждым событием, и сайт отбрасывает чужие: без этого кто угодно мог бы слать вам «сообщения от клиентов». Необязательно, но с ним — безопаснее. Сейчас: {{ 'задан' if settings.get('vk.secret') else 'не задан' }}.
