## Как проверить живость одной командой

```
node scripts\check-live.js
```

Скрипт проверяет https, срок сертификата, оба контейнера и совпадение статики на проде с `build/dist`.

## Порты и провайдер — важное

Порт 80 снаружи перехватывает оборудование провайдера: оно отвечает 403 `Server: Web server`.
Наш nginx этих запросов не видит. Отсюда правило: сайт живёт на **443**, а «без s не открывается» —
это не поломка сайта.

Сертификат выпускается и продлевается по **TLS-ALPN-01 через 443**. HTTP-01 не подходит:
валидация по 80 не пройдёт никогда, пока порт перехвачен. Скрипт — `scripts\renew-cert-guarded.js`,
перед перевыпуском проверяется, что до конца срока не больше 30 дней; при смене состава доменов —
только с `--force`.
